# ADR-023 — LangGraph.js: 그래프 모양 워크플로 전용 실행 엔진

**상태:** accepted (시범 운영 — 2026-11-16 판정)
**날짜:** 2026-10-03
**관련:** ADR-011(작업 큐 FSM — LangGraph 거절, 그 범위에서 유지) · ADR-018(서브에이전트 병렬) · ADR-020(Langfuse — 현재 미가동)

---

## 배경

- 자비스는 OpenClaw(2026.9.x) 위에서 돈다. 예약 자동화 135개 중 켜진 것은 99개이고, 그 93%가 명령을 한 번 돌고 끝난다. 조건 트리거를 쓰는 자동화는 0개다.
- 몇 시간짜리 LLM 반복 작업(첫 대상: 앱 QA 버그 사냥·수정 루프)은 게이트웨이 재시작에 끊긴다. OpenClaw 예약은 끊긴 실행을 이어 하지 않는다. 재기동 때 밀린 agent-turn은 다시 일정에 넣을 뿐이고, 기한을 주지 않은 agent-turn은 60분 감시에서 끊긴다(`docs/automation/cron-jobs/how-it-works.md`).
- LangGraph 핵심 기능 12개 가운데 OpenClaw와 Claude Code가 6개는 그대로 대신하고 6개는 일부만 대신한다. 남는 빈틈은 넷이다.
  - 크래시 뒤 단계 단위 결정적 재개
  - 과거 상태를 고쳐 다시 실행
  - 재시작해도 살아남는 사람 승인 대기
  - 시각 디버거

## 결정

- **LangGraph.js**(`@langchain/langgraph` 1.4.18, MIT)를 그래프 모양 일의 전용 엔진으로 들인다. 대상은 LLM이 분기를 정하거나, 반복·병렬·사람 승인·장시간 대기가 있는 일이다. 예약은 계속 OpenClaw 하나로 한다.
- **체크포인트**는 `@langchain/langgraph-checkpoint-sqlite` 1.0.4로 저장한다.
  - 위치는 저장소 밖 런타임 상태 폴더이고, 권한은 600이다.
  - `secure_delete` 를 켜고, 14일이 지나면 정리한 뒤 VACUUM한다.
- **LLM 호출**은 노드 안에서 Claude Code CLI(구독 로그인)로 한다.
  - `--setting-sources project` 로 사용자 훅을 막는다.
  - LangChain 모델 래퍼(API 키 경로)는 쓰지 않는다.
- **LangSmith 추적은 쓰지 않는다.** 실행기가 추적 환경변수 4종을 시작할 때 지운다.
- **범위 밖:** 기존 자동화 이전, 감시·당직 영역, Python판.

## 검토한 대안

| 대안 | 판정 | 이유 |
|---|---|---|
| OpenClaw Lobster | 미채택 | 순차 단계·승인·재개 토큰은 있으나 반복 구문이 없고, 내장 llm-task가 "not currently reliable"(`docs/tools/lobster.md:192`) |
| OpenClaw Swarm · Claude Code Workflow | 미채택 | 1회성 수집이거나 세션 안에서만 재개된다. 장시간 내구 실행이 안 된다(`docs/tools/swarm.md:599-602`) |
| 직접 만든 단계 기록기(node:sqlite) | 미채택 | 의존성은 0이지만, 반복·병렬·분기를 담으려면 결국 그래프 엔진을 다시 짓게 된다 |
| Inngest 자가호스팅 | 보류 | 상주 서버가 하나 늘고, 자가호스팅이 Beta이며 서버 라이선스가 SSPL이다 |
| Mastra | 미채택 | 의존성 151개, 12개월 동안 1,082회 배포로 변동이 크다 |
| Temporal · DBOS · Restate | 미채택 | 별도 서버나 Postgres가 필요하다 |

## ADR-011과의 관계

ADR-011이 든 거절 이유 셋을 다시 본다.
- **"Python 의존":** 당시에도 사실과 달랐다. JS판은 2024-01에 첫 배포됐고, 1.0은 2025-10-18에 나왔다.
- **"수십 MB":** 유효하다. 실측 결과 패키지 60개, 76MB다.
- **"네이티브 부품 재빌드":** 유효하다. ADR-011은 better-sqlite3 자체도 거절했다(ADR-011:28). 이번에는 미리 빌드된 판(12.11.1, Node 24 arm64)을 고정하고, 시작할 때 자가 시험을 한다. Node 내장 SQLite로 저장 모듈을 바꾸는 안은 0단계 뒤 검토 과제로 남긴다.

6상태 작업 큐에는 지금도 LangGraph가 필요 없다. ADR-011의 결정은 그 범위에서 그대로 유지한다.

## 안전장치

| # | 안전장치 | 막는 위험 |
|---|---|---|
| S1 | 스레드별 잠금 | 동시 재개로 승인·반려가 둘 다 실행됨 |
| S2 | 이미 있는 스레드에 start가 오면 거부 | 대기 중 재시작으로 처음부터 다시 돎 |
| S3 | 추적 환경변수 삭제 | 변수 하나로 외부 전송 |
| S4 | 원문 대신 참조 저장 · secure_delete · 14일 gc · 권한 600 | 개인정보 평문 누적 |
| S5 | interrupt 노드에 LLM·부수효과 금지 + 정적 검사 | 재개 때 노드가 다시 돌아 승인 안 받은 결과가 나감 |
| S6 | 네이티브 부품 자가 시험 + 설치 스크립트 승인 | Node가 바뀌면 조용히 죽음 |
| S7 | 사용자 훅 차단 | 위키·RAG·세션 기록 오염 |
| S8 | 스레드·하루 호출 상한, 최상위 모델 금지, 주간 사용량 문턱 | 구독 한도 잠식 |
| S9 | 승인 48시간 만료 + 대화 첫머리 노출 | 멈춘 일이 안 보임 |
| S10 | 부수효과 멱등 키 + 원장 | 재시도 때 커밋·배포가 두 번 일어남 |
| S11 | 멈춤 스위치 | 즉시 정지가 필요할 때 |
| S12 | 폐기 조건: 2개월 미사용 또는 3회 고장 | 방치 |

## 결과와 판정

- **단계:** 뼈대 → 그림자 모드 2주(부수효과 없이 '고칠 안'까지만) → 실제 반영 4주 → **2026-11-16 판정.**
- **지표:**
  - 재시작으로 버려진 실행 0
  - 검증 없는 완료 0
  - 중복 부수효과 0
  - 보고 없이 버려진 승인 대기 0
  - 추가 금전 비용 0
  - 운영자가 먼저 찾은 루프 고장 0
- **실패하면:** 잡을 끄고, 코드 커밋을 되돌리고, 상태 폴더를 폐기한다. 그리고 이 ADR에 폐기 이유를 적는다.

## 근거 — 실물 시험 (2026-10-03, macOS arm64 · Node 24.21)

| 항목 | 결과 |
|---|---|
| 설치 | 7.1초, 60패키지, 76MB. better-sqlite3 12.11.1이 미리 빌드된 파일로 깔림 |
| 크래시 재개 | 죽은 노드부터 다시 돎. 앞 노드는 다시 돌지 않음 |
| 되감기 | `updateState` 로 고쳐 다시 실행됨. 원래 갈래는 보존됨 |
| 외부 연결 | 추적 변수가 없으면 0건(프록시 차단·샌드박스로 확인). 변수가 `"true"` 면 키 없이도 전송을 시도함 → S3 |
| Claude 호출 | `claude -p` 6.6초, Agent SDK 3.9초. 둘 다 로그인 인증(`apiKeySource: none`) |
| 발견한 위험 | 동시 재개 이중 실행, 체크포인트 평문(삭제 뒤에도 남고 VACUUM 해야 지워짐), 설치 스크립트를 건너뛰면 실행 때 죽음 → S1·S4·S6 |
