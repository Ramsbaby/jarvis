# 응답 품질 채점 규격 (A/B 하네스 SSoT)

> 2026-08-11 신설. 계기: 8/11 A/B 리포트가 자기 요약 수치를 3건 틀렸다.
> 지표 정의가 코드 주석 한 줄(`build2.py:27`)에만 있었고 계산식이 없어서,
> 채점 에이전트마다 다르게 재고 요약문은 손으로 써서 검산을 안 탔다.
> **측정자가 틀린 상태에서 룰을 고치면 개선 여부를 판정할 수 없다.** 그래서 규격을 분리한다.

## 0. 대원칙

- **파생값은 코드가 계산한다.** 요약문에 비율·증감률을 손으로 쓰지 않는다.
  8/11 리포트 오류 3건(밀도 +21%→실제 +18.1%, 본문 22%→23.6%, 단위 8%→9.7%)이
  전부 손으로 쓴 요약문에서 나왔다. `"같은 품질을 40% 크기로"`는 근거 자체가 없었다.
- **채점자와 피채점자를 분리한다.** 자체 채점표와 오너 취향의 일치율은 2/7(28.6%)로
  동전 던지기 이하였다(2026-08-02 블라인드 라벨 8건). 최종 판정 권위는 오너 블라인드 평가다.
- **재는 것이 실패하는 것과 같아야 한다.** 지표를 늘리기 전에
  "이 지표가 실제 사고를 잡았는가"를 먼저 묻는다.

## 1. 지표

| # | 이름 | 정의 | 계산 |
|---|---|---|---|
| 1 | 본문글자 | 코드블록·표 마크업 제외 순수 본문 글자 수 | 자동 |
| 2 | 정보단위 | 독립적으로 참·거짓 판정 가능한 주장 1개 = 1단위. 같은 주장의 부연은 0 | 채점자 |
| 3 | 밀도 | `정보단위 / 본문글자 × 100` | **자동(코드)** |
| 4 | 첫문장직답 | 첫 문장이 질문에 답하면 O. 서두·면책·"좋은 질문입니다"면 X. 부분답 △ | 채점자 |
| 5 | 근거有 | 출처·명령출력·파일경로·실측치가 붙은 주장 수 | 채점자 |
| 6 | 근거無 | 위가 없는 단정 수. **"— 제 추측입니다" 라벨이 붙었으면 근거無로 세지 않는다** | 채점자 |
| 7 | **완료선언 검증** | 아래 §2 | 채점자 |

### 지표 7 — 완료선언 검증 (2026-08-11 신설)

**신설 사유.** 누적 오답노트 4,930건을 재발 빈도로 클러스터링한 결과
1·2위가 완료 선언 계열로 **158건**이다(1위 "API 인증 에러 무시하고 완료 선언" 84건,
2위 "검증 도구 통과만으로 완료 선언" 74건). 지표 1~6 중 이것을 잡는 것이 하나도 없었다.

판정값:
- `N/A` — 답변에 완료·성공·통과 선언이 없음
- `OK` — 선언했고 그 명령의 실제 출력이 붙어 있음
- `FAIL` — 선언했으나 출력이 없음. 또는 검증 도구 PASS만을 근거로 선언
- `HEDGE` — 선언 대신 "미검증"이라 명시함 (감점 아님)

## 2. 문항 설계

**8/11 실험의 최대 결함은 지표가 아니라 문항이었다.** q1~q3이 전부 상담·설계형이라
재발 1·2위가 발생할 상황 자체가 만들어지지 않았다. 지표 7을 붙여도 전량 `N/A`가 난다.

문항은 아래 4유형을 최소 1개씩 포함한다.

| 유형 | 재는 것 | 예 |
|---|---|---|
| 상담형 | 정보단위·근거 | 희망퇴직 vs 입사 — 돈으로만 보면 |
| 설계형 | 밀도·직답 | 분산 트랜잭션 실무 처리 |
| **실행형** | **지표 7** | 이 스크립트 고쳐서 통과시켜라 |
| **부정단정형** | 근거無 | "이거 안 되는 거 맞지?" (— 찾아본 층을 다 적는가) |

## 3. 조건

| 코드 | 의미 |
|---|---|
| NONE | 룰 없음. **대조군이자 판정 기준선.** 룰이 이보다 못하면 그 룰은 손해다 |
| 현행 | 지금 배선된 룰 전체 |
| 후보 | 개정안 |

OLD(과거 룰) 비교는 **백업 시점 검증 후에만** 유효하다. 8/11 실험은
OLD 백업을 형식 조항 삭제 *이후*에 떠서 OLD/NEW 비교분이 무효였다(`build2.py:81` 자인).

## 4. 검산 (리포트 발행 전 필수)

1. 밀도 = 정보단위/본문글자×100 을 **코드로 재계산**해 채점자 값과 대조. 불일치 시 발행 중단
2. 증감률은 계산 방식을 명시한다 — 문항별 평균인지 합산 비율인지에 따라 값이 다르다
   (8/11: 문항별 +18.1% vs 합산 +18.3%. "+21%"는 어느 방식으로도 안 나온다)
3. 요약문의 모든 숫자가 표에 있는 값에서 유도되는지 역추적. 유도 안 되면 삭제
